### Sheets Included
1. **Dashboard** - Live KPIs, brand performance, pipeline funnel
2. **Lead Tracker** - Main data entry for leads & prospects (with dropdowns)
3. **Targets** - Set monthly targets; actuals calculate automatically
4. **Activity Log** - Record calls, emails, meetings, follow-ups
5. **Instructions** - How to use the template

### Key Features
- Tracks leads through stages: New Lead → Prospect → Qualified → Proposal → Won / Lost
- Brand coverage: Posh Hotels & Suites, Hotel Per Hour, Streetfood NG, Amazonas/Creatif, Gold Privilege, Inovacao Ltd
- Conversion rates, pipeline value (NGN), target achievement %
- Sample data included for immediate use
- Professional formatting, filters, and auto-calculations

### How to Use
1. Download the .xlsx file using the link above
2. Open in Microsoft Excel or Google Sheets (upload to Google Drive)
3. Enter new leads starting from row 8 on the Lead Tracker sheet
4. Update Status and Owner as opportunities progress
5. Review the Dashboard weekly against targets

**Recommended:** Upload the Excel file to Google Drive and share a view/edit link with the marketing and sales team for collaborative use.

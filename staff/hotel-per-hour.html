6. Weekly Report Notes (Friday by 5pm)

Guest-Ready Standard (10-point checklist)

  1. Authorised partnership form + rates on file; registered online
  2. Named ops contact + working 24h / late-arrival number tested
  3. Exterior + reception + ≥2 room photos (refreshed ≤90 days)
  4. At least one room type bookable with hourly and/or half-day rates
  5. Room clean, AC, functioning bathroom, toiletries, linens
  6. Power backup confirmed and described honestly
  7. WiFi tested on-site
  8. Front-desk briefed on HPH check-in flow
  9. No unresolved safety / security / guest-surprise issues
  10. Test path: dummy booking walkthrough completed
Partial compliance = Conditional (not Ready). Only hotels passing all 10 count as Live / Guest-Ready.
